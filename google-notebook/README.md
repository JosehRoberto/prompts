## Prompts para Google Notebook

O objetivo principal é fornecer um guia prático de prompts (comandos) para otimizar o uso do Google Notebook no contexto educacional/acadêmico. Serve para  orientar estudantes ou profissionais sobre como transformar seus próprios materiais de estudo carregados na plataforma em recursos estruturados para aprendizado, revisão, autoavaliação e planejamento de estudos.
