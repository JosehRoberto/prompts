# Transforme Vídeos do YouTube em Cursos no Google Notebook

O Google Notebook pode transformar tutoriais do YouTube em um sistema de aprendizado completo.
Insira o link de um tutorial no Google Notebook e use estes prompts para transformar o vídeo em aulas, exercícios práticos, projetos, avaliações e um plano para aplicar o que você aprender.

## Transforme este tutorial em um curso

```markdown
Transforme este tutorial do YouTube sobre [TÓPICO/HABILIDADE] em um curso completo, não apenas um resumo. Organize-o do nível iniciante ao avançado. Explique cada conceito, defina termos-chave, forneça exemplos e analogias, identifique erros comuns e informações ausentes e encerre cada aula com os pontos principais e exercícios práticos. Adapte o conteúdo ao meu nível: [INICIANTE/INTERMEDIÁRIO/AVANÇADO].
```

## Crie um roteiro para dominar o assunto

```markdown
Transforme este tutorial sobre [TÓPICO/HABILIDADE] em um roteiro de aprendizado, indo do nível iniciante ao avançado. Inclua pré-requisitos, ordem de aprendizado, marcos, habilidades práticas, cronogramas, critérios de sucesso e indicadores de progresso. Meu objetivo é [RESULTADO DESEJADO] e tenho disponibilidade para estudar [TEMPO POR DIA/SEMANA].
```

## Crie um plano de prática

```markdown
Crie um plano de prática de [30/60/90] dias com base neste tutorial. Inclua exercícios diários, desafios de dificuldade crescente, miniprojetos, revisões, repetição espaçada, avaliações semanais, metas e pontos de verificação. Adapte o plano para o nível [INICIANTE/INTERMEDIÁRIO/AVANÇADO] e para [TEMPO DISPONÍVEL POR DIA]. Meu objetivo é [META ESPECÍFICA].
```

## Transforme conhecimento em ação

```markdown
Extraia o conhecimento prático deste tutorial sobre [TÓPICO/HABILIDADE]. Transforme-o em um guia de execução (playbook) contendo estratégias, estruturas (frameworks), fluxos de trabalho, checklists, ferramentas, modelos, melhores práticas e etapas de implementação. Priorize o que é mais importante para alcançar o [RESULTADO DESEJADO]. Torne o material utilizável sem a necessidade de assistir ao vídeo novamente.” 
```

## Encontre as Peças que Faltam

```markdown
Analise este tutorial sobre [TÓPICO/HABILIDADE]. Identifique conceitos omitidos, premissas implícitas, técnicas avançadas, orientações desatualizadas, erros comuns de iniciantes e lacunas de aprendizado. Em seguida, liste o que devo estudar a seguir para alcançar [NÍVEL/RESULTADO DESEJADO], categorizando os tópicos em essenciais, úteis e avançados.
```

## Teste Meu Conhecimento

```markdown
Crie uma avaliação de domínio baseada neste tutorial sobre [TÓPICO/HABILIDADE]. Inclua [NÚMERO] perguntas desafiadoras, cenários do mundo real, tarefas de resolução de problemas, estudos de caso e desafios práticos com nível de dificuldade [DIFICULDADE]. Explique cada resposta, identifique meus pontos fracos e elabore um plano de melhoria com base nos meus resultados.
```

## Desenvolva Projetos do Mundo Real

```markdown
Crie três projetos baseados neste tutorial: um para iniciantes, um intermediário e um avançado. Para cada um, inclua o objetivo, as ferramentas, os marcos, as entregas, os critérios de avaliação, as armadilhas comuns e as extensões opcionais. Torne-os relevantes para [SETOR/CASO DE USO]. O projeto final deve demonstrar [HABILIDADE/RESULTADO ESPECÍFICO].
```

## Crie um Guia de Referência

```markdown
Transforme este tutorial sobre [TÓPICO/HABILIDADE] em um guia de referência para [FINALIDADE]. Inclua resumos concisos, folhas de consulta rápida (cheat sheets), fluxogramas, árvores de decisão, fórmulas, checklists, guias de solução de problemas, perguntas frequentes (FAQs), insights principais e uma referência rápida de uma página. Priorize as informações que utilizarei com mais frequência.
```
